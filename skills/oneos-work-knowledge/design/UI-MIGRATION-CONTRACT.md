# OneOS 视觉升级与业务保护契约

版本 1.1 · 2026-09-11 · 适用于存量 Vue + Ant Design Vue + Vben + VXE 前端。

## 四层职责

| 层 | 负责 | 禁止接管 |
|---|---|---|
| 主题 | 语义色、字号、控件高度、圆角、焦点、深浅色 | 数值格式、默认值、业务状态推导 |
| 页面结构 | 内容宽度、分区、筛选与表格排列、页尾操作位置 | 查询时机、路由、提交与关闭行为 |
| 现有控件 | 继续使用 Ant、Vben 表单与 VXE | 为贴近 React 而替换表格或重建表单引擎 |
| 业务页面 | 原有取值、规则、依赖、权限及事件 | 把范例的假数据与演示规则带入业务 |

组件基于 Vue 命名插槽承载页面已有内容，保持父页面的数据和事件作用域。见 [Vue 官方插槽文档](https://vuejs.org/guide/components/slots.html)。规范遵循 [Ant Design 一致性与模块化原则](https://ant.design/docs/spec/values/)，主题接线使用 [Ant Design Vue ConfigProvider](https://antdv.com/components/config-provider)。

## 必须冻结的业务行为

| 项 | 前后对照内容 |
|---|---|
| 数据 | 来源、字段名、类型、空字符串/null/0 的区别、默认值、枚举值与顺序 |
| 金额和日期 | 单位、精度、格式化时机、提交原值、时区、范围与起止边界 |
| 表单 | 必填、长度/数量/大小限制、禁用/只读、联动、校验触发与提示、关闭未保存提醒 |
| 台账 | 查询与清空参数、立即查询或手动查询、分页、排序、选中及跨页保留、列显隐权限 |
| 动作 | 权限、按钮条件、暂存与提交区别、二次确认、重复提交锁、成功与失败的副作用 |
| 业务判定 | 临期、逾期、结清、异常、可编辑、可办理等由原页面提供，UI 只显示 |

任何一项发生变化，任务即超出纯视觉迁移；记录变化并回到对应产品决定，不用“统一规范”解释掉差异。

## 搜索与组合筛选

2026-09-11 用户采纳：统一搜索区外观，按页面现有查询能力配置范围，保留原有组合筛选。产品决定见 [冻结合同](./.spec/product-contract.md)「搜索范围澄清」；本节只解释迁移约束。

| 能力情况 | 处理方式 |
|---|---|
| 现有接口已支持相同条件及组合方式 | 复用原请求、参数转换、权限、分页、排序与导出；同表或多表不影响该分类 |
| 现有接口仅支持分字段组合，需要新增一框多字段任一命中 | 保留分字段搜索；新增 OR 搜索另列需求，不能把一个词同时填入多个 AND 参数冒充合一搜索 |
| 新增跨服务、历史记录或派生汇总筛选 | 先明确对象、历史范围、关系、权限与性能，再单独评估；不属于本轮视觉替换 |
| 后端版本或行为证据不足 | 标记待核对，保留当前可用路径；不得将未验证能力写进搜索占位文案 |

- 字段可以合并的前提是搜索范围、精确/模糊方式、组合逻辑及结果范围完全等价；关键词搜索不能自动替代精确组合筛选。
- 页面已有字段数量、顺序、单选/多选、空值、日期起止边界、展开状态与触发时机继续有效。不得为“更多筛选 ≤8”删项。
- 控件里的选项检索与台账结果检索分别核对；选项能按名称检索，不代表列表接口支持跨字段模糊匹配。
- 禁止拉取当前页后过滤、合并多个分页响应、私自全量拉取来模拟全量智能搜索。结果、总数、排序、分页、导出和权限必须保持同一已验证口径。
- 公共组件只接收页面已有控件和事件，不推断字段来源，不改写 AND/OR，不创建新的搜索权限或请求协议。
- 失败沿用原恢复路径，不忽略未支持的条件后返回结果，也不将请求失败显示为“没有数据”。

每页登记条件含义、原控件、参数与转换、数据来源、组合方式、能力证据和迁移分类。数据库映射只放技术清单，不进入产品合同或业务界面。首批见 [车辆与客户能力清单](./.spec/search-capability-inventory.md)。

## 页面与组件标准

- **台账**：筛选、工具行、表格、分页形成连续内容面。保留原字段顺序；主操作显著。表格使用原列定义与数据，长内容完整可读，横向滚动时操作列可达。
- **表单**：已有分组与字段保持对应；最多三列，以容器宽度收为两列、一列。标签 13px、辅助文本 12px，错误必须有文字。必填星号不能替代业务校验；公共组件不新建校验。
- **详情**：先展示对象身份与业务给定的状态，再展示分组属性和记录。只读值不伪装成可编辑框；长值换行，数字不裁断，无值不编造。复制能力不能改变显示或原值。
- **控件**：PC 默认 36px / 圆角 10px / 正文 13px；密集档 32px 是已有可选档，不能因此隐藏内容；触控目标至少 44px。字号和间距遵循现有 Token，页面不写另一套颜色。
- **状态**：常规、悬停、键盘焦点、禁用、只读、错误、加载均有表达。空结果与加载失败分开；重试调用页面原事件。加载期间保留容器尺寸；不能把失败当空结果。
- **可访问性**：普通文本对比度目标至少 4.5:1；状态不只依赖颜色。焦点可见，弹层保留控件原生键盘与关闭行为；遵循减少动态效果偏好。禁用不承担必读业务信息，必要信息另作可读文字。
- **深色**：容器、表头、行悬停、浮层、错误与只读均由主题决定，不出现强制白底；主色按父级传入的主题偏好变化。

## 历史样板可运行范围（DS-PILOT-01，2026-09-10）

`DS-PILOT-01` 是当时独立 Vue 规范样板，使用当时锁文件版本的 Ant/VXE。三个页面展示范例字段；所有演示数据、临时筛选与暂存均位于展示入口，正式公共组件没有接口调用或业务默认值。当时原生产入口、菜单、路由和业务文件未接入该试验。本段只记录历史样板边界，不能用于判断当前本地或测试部署的接入状态；本轮须从目标测试部署源提交另行核对。

## 开发使用顺序

1. 从目标测试部署锁定源提交，保存工作区改动并记录当前业务行为。
2. 完成筛选能力清单，将可复用、待核对和需要新增查询能力的项分开；只对已有能力做视觉接入。
3. 复用公共页面结构，把原表单、表格和按钮原样放入插槽；保留现有属性、事件、权限指令和 model。
4. 对照已有主题合并语义 Token。不要因为某个旧本地分支接过主题，就推断最新测试分支也接过。
5. 对照冻结项检查输入与请求参数；至少覆盖正常、边界、无权限、空值、失败与重复点击；同一筛选样例核对列表、分页与导出。
6. 完成本地验证后交开发构建部署，再对测试环境做回归；本地视觉验证不等于测试验收，也不能承诺完全免回归。

## 废止的全站默认解释

“3 天内临期”“30 天内到期”“金额两位小数”“最多 6 张/10MB”“查询后自动折叠”等只属于原例子或单独确认过的业务。其原例子不被删除，但不得作为其他页面的业务规范。

“全部页面必须合一智能搜”“关键词提到某字段就删除独立筛选”“为满足 ≤8 项裁剪存量字段”不再作为全站迁移要求。原型里的演示匹配保留作追溯，不代表正式接口已有能力。
