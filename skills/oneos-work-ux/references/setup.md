# 项目接入与可移植性

先检查当前工具、项目配置和真实远端，不执行自动安装或初始化云端库。Python 3.9+ 是附带脚本唯一必需运行时；源码开发按目标项目环境，Midscene 仅在执行 UI 自动化时安装。

从现有上下文补齐并保存一份 `project.json`，结构见 config/project.example.json：业务仓库、测试分支、平台正式对象、测试环境、组件版本读取方法、账号角色、测试数据策略、设计来源。未知项保持 null；只阻塞依赖它的动作。凭据放环境/平台凭据管理器，配置只存引用名。

HiFox 与云效是可替换工具层。先用 CLI --help 或可用连接器确认操作和字段，不照搬另一平台状态名。HiFox 资源只用 hifox CLI，读命令用 --output json；文件下载用 attachment download。云效也只用已认证官方 CLI/连接器；没有工具则明确未接线，不用评论冒充状态改变。除用户要求，不为一次咨询自动创建任务。

HiFox 独立技能导入须保留 SKILL.md 及其引用文件；若只粘贴 SKILL.md，启动就说明资源缺失，不能声称工具和规范可用。入口文件中一切相对路径都相对该入口目录。完整性检查：`python3 scripts/doctor.py`。四个入口可以各自单独读取共用方法，不要求同级目录安装；安装多个入口时 packageId 和 sharedDigest 不一致应先明确版本差异。

配置知识工具：`python3 scripts/kb.py --help`。推荐授权连接器按提交取文件；附带工具也支持 Codeup 只读 PAT（环境变量 ONEOS_CODEUP_TOKEN）或 --repo 指向已有 Git 对象。API 固定中央版官方域名，其他地域版本应通过经验证适配器接入，不把凭据发给任意配置 URL。

环境就绪与功能可用分开回执：文件完整、Python 工具可用、双库授权可用、测试浏览器可用、模型可用、项目账号可用。未配置模型不阻断 API/确定性测试，但不能宣称 AI 视觉执行通过。
