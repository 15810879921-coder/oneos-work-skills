# OneOS 体验规范

独立工作体系 v1.0.0；不依赖团队 FDE。

先读 [共用协议](references/contract.md) 与 [体验规范职责](references/design.md)，随后按 [规范阅读索引](design/INDEX.md) 只读适用正文/范例。本入口保留独立标准维护权，交付与验证也使用同一份标准。

随包是可追溯固定快照，不冒充实时云端版本；当前任务如有已核实的新规范，锁定新来源和替代关系。规范完整性运行 scripts/doctor.py；缺文件不能用旧页面或模型审美替代。

负责：适用规范、页面范式、标准组件与同栈依据、交互/状态、设计审查与例外。业务动作和权限来自业务规则；变更规范要有实际决定与版本，不为掩盖失败改标准。

用 [评审模板](templates/design-review.md) 输出条款、问题、改法、证据和未决项。页面改码交 [交付方法](references/delivery.md)，实际验证交 [验证方法](references/testing.md)；职责入口本身不等于代码修改或验收通过。完整云端同步按 [知识方法](references/knowledge.md)。
