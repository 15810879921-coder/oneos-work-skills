# OneOS 独立工作体系 v1.0.0

面向王冕的独立工作方法。四个入口，不依赖何斐维护的团队 FDE；开发推进到测试分支后等待测试人员统一部署，部署后继续验证与返修。保留独立体验规范职责。

## 导入

总包用于保存和传递，不作为单个 Skill 导入。解压后每个 `oneos-work-*.zip` 是一个独立技能，ZIP 根目录有 SKILL.md 及完整引用目录；`skills/` 同时提供解压后的相同内容。

| 技能名称 | 单独的ZIP/文件夹 | 用途 |
|---|---|---|
| OneOS 独立交付 | oneos-work-delivery | 需求、实现、自检、测试分支交接 |
| OneOS 独立验证 | oneos-work-verify | 部署版本核验、测试、缺陷和复测 |
| OneOS 双库知识 | oneos-work-knowledge | 业务/开发库检索、关联与沉淀 |
| OneOS 体验规范 | oneos-work-ux | 设计标准、页面评审与例外 |

在你客户端的本地技能导入入口逐个选择独立 ZIP；若入口接受文件夹，选择 skills 下对应文件夹。必须保留全部引用文件，不能只复制 SKILL.md。若当前客户端仅提供正文编辑和附件文件管理，应将 SKILL.md 作为正文、其余文件按相对路径添加；若无法导入完整资源，应先停下，不能把“只贴正文”当完整安装。

本次未代你导入或修改 HiFox 技能。已确认本机 CLI 的 skill import 只支持 URL，不接受本地 ZIP；未对 HiFox 客户端本地导入执行真实验收。包提供标准 SKILL.md 格式、独立 ZIP 和完整目录，便于按实际客户端能力手动导入；不调用未知平台 API。

安装后让 Agent 定位当前技能目录并运行 `python3 scripts/doctor.py`。它验证包内文件的清单一致性（实际filesChecked以输出为准，manifest本身不纳入自身哈希）。如只导入正文、丢失目录或文件被改写，会报告缺失/变更。

四包可单独使用，公共协议、工具和设计快照由同源生成，sharedDigest相同，不要求安装在相邻目录。升级时同步更新已安装的相关入口，避免混用协议版本。不要把这套与团队 FDE 的相反流程规则同时作为同一任务入口。

## 怎么用

- “用独立交付处理这个需求，完成后进入测试分支，等待统一发版。”
- “测试环境已经更新，用独立验证检查这个交付；先核实际部署版本。”
- “从双库查这条业务规则，并列出对应实现与证据缺口。”
- “用体验规范评审这个页面，按当前 OneOS 正式标准给问题和改法。”

新项目第一次需要真实仓库、目标分支、平台任务、测试环境/角色与数据约定。Agent先查询可取得的信息，只问剩余缺口；config/project.example.json是结构示例，不要求你手填所有字段。未知依赖只阻塞相关动作。

## 资源和凭据

- Python 3.9+：双库只读工具与结构检查器，无第三方Python依赖。
- 双库正式正文仍在现有 Codeup，不随包克隆。可用授权连接器读取，或设置安全环境变量 ONEOS_CODEUP_TOKEN，或指向已有Git对象。无需把密钥写入技能。
- 知识缓存默认32MiB，按提交/文件缓存；不把缓存等同于模型已读或业务已确认。云端API读取实现已测解析/完整性边界，本次真实知识验证使用已有Git对象，未用PAT实连API。
- Midscene模板在 assets/midscene。复制到项目测试目录后 npm ci，按环境使用Chromium；首次需要浏览器和模型、测试账号配置。锁文件已随包。不要在技能安装目录长期堆依赖/报告。
- `.env.example` 只提供配置键，没有任何密钥。无模型/环境时AI测试前置会失败，不能算测试通过。
- 设计快照包含当前规范、Token和部分Vue同栈文本源码，来源 oneos-design-system-20261027-current。它是有来源哈希的固定派生快照，不是完整可运行规范站；没有图片、字体、编译预览和宿主依赖。尚未迁到云端设计正本，后续迁移须维护正式来源关系。

## 你会拿到的结果

开发结束：实际合入与检查证据、测试交接、依赖与缺口，状态为等待统一部署。不会抢测试人员部署。
测试结束：按AC给真实通过/失败/阻塞/未执行、版本与证据；返修回测试分支再次等待部署。不会自动生产发布或伪造独立QA。
知识整理：当前来源和关联状态、净变化、实际远端同步结果；尚未同步的明确标记，不把本地文件当云端落盘。

## 维护

业务知识与开发知识继续由原有云端仓库保存；本次未更改两库或原Skill。运行记录用已授权任务平台保存；图片/日志/视频放云端附件或制品。本地只留活动工作区和限额缓存。

本套工具不包含自动部署器、自动后台唤醒、云端知识写入器或预配置模型。后续动作由具备真实授权的Agent和官方平台工具执行。Skill不能替代运行环境、账号、模型及业务验收证据。

逐项验证与未接线边界见《验证报告.md》，文件完整性见 SHA256SUMS.txt 和每个包的 package-manifest.json。
